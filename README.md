# Cryptography and Network Security (CNS) - Semester 5

This branch (`CNS_5sem`) contains comprehensive academic resources, lecture notes, and study materials for the **Cryptography and Network Security (CNS)** course under the Artificial Intelligence curriculum.

## 📁 Branch Structure

The directory contains structured PDF files covering foundational and advanced concepts in network security:

* 📄 **unit 1 CNS.pdf** — Introduction to Security Concepts, Vulnerabilities, and Classical Encryption Techniques.
* 📄 **unit 2 CNS.pdf** — Symmetric Key Cryptography (DES, AES) and Block Cipher Operations.
* 📄 **unit 3 CNS.pdf** — Asymmetric Key Cryptography (RSA, Diffie-Hellman Key Exchange) and Hash Functions.
* 📄 **unit 4 CNS.pdf** — Network Security Protocols (SSL/TLS, IPsec), Digital Signatures, and Firewalls.
* 📄 **unit 5 CNS.pdf** — System Security, Intruders, Malicious Software, and Trust Management.
